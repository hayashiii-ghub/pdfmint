# pdfmint でできること

Markdown を `pdfmint demo.md demo.pdf` の一発で、提出できる日本語 PDF にします。これは **デフォルト設定（preset なし）** の出力例です。

## 書ける記法

見出し・**太字**・*斜体*・`インラインコード`、箇条書き／番号付きリスト、引用、表に対応します。

- フロントマターは本文に漏れず、`title` が文書タイトルになります
- 脚注[^1]・GitHub 形式の callout・コードのシンタックスハイライトも標準対応

## 表（数値は右揃えできる）

| 項目 | 金額（円） |
|---|---:|
| 制作費 | 150,000 |
| 運用保守（年額） | 50,000 |
| 合計 | 200,000 |

## callout とコード

> [!NOTE]
> 補足や注意は、この形式で目立たせられます。

```ts
const html = markdownToHtml("# Hello", { font: "serif" })
```

[^1]: 脚注は文書末にまとめて出力されます。
