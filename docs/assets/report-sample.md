# 2026年5月 月次サイトレポート

本レポートは2026年5月のアクセス状況と改善施策の結果をまとめたものです。前月比でセッション数が12%増加し、特に検索流入の伸びが顕著でした。

## アクセス概況

| 指標 | 4月 | 5月 | 前月比 |
|---|---:|---:|---:|
| セッション数 | 4,210 | 4,715 | +12.0% |
| ユニークユーザー | 3,180 | 3,492 | +9.8% |
| ページビュー | 11,840 | 13,205 | +11.5% |
| 直帰率 | 58.2% | 54.1% | -4.1pt |
| 平均滞在時間 | 1:42 | 1:58 | +16秒 |

検索流入の内訳では、ブランド名キーワードが全体の34%を占めました。指名検索の増加は4月に実施したSNS施策の効果が継続していると考えられます。

> 改善施策のうち、トップページのファーストビュー刷新が直帰率低下に最も寄与したと考えられます。ヒートマップ上でもスクロール到達率が改善しています。

## 実施した施策

1. トップページのヒーローセクション刷新
2. 主要ページの meta description 見直し
3. 画像の WebP 化による表示速度改善

### 技術的な変更

```bash
# 画像の一括変換と表示速度の計測
cwebp -q 82 hero.png -o hero.webp
```

LCP(最大コンテンツの描画)は 2.8s → 2.1s に改善しました。

数値は全体に好調ですが、検索流入の伸びに対してコンバージョンが横ばいです。来月はフォーム導線の改善を優先し、流入増を成果につなげる段階に移ります。
